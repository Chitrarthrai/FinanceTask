## Brand & Style
Titanium Industrial Modern is an ultra-tactile, high-density design system engineered for next-generation financial and task management applications. It combines the precision of aerospace instrumentation with high-end dark/light glassmorphic aesthetics.

## Colors
Dual-mode architectural spectrum:
- **Dark Mode (Default)**: Deep Obsidian `#090A0F` base, `#12151E` glass container cards, with glowing Electric Cyan (`#00F2FF`), Hyper Violet (`#7C3AED`), and Luminous Mint (`#00FF9D`).
- **Light Mode**: Precision Slate `#F8FAFC` base, `#FFFFFF` crisp glass cards, Indigo headers (`#0F172A`), Electric Azure (`#0284C7`), and Emerald Mint (`#059669`).

## Micro-Animations & UI Elements
- **Bento Grid Architecture**: Modular, glass-paneled card layout with 1px rim lights (`rgba(255, 255, 255, 0.1)`).
- **Tabular Data Focus**: Financial metrics rendered in `JetBrains Mono` with animated spring counters.
- **Interactive Lighting**: Glow effects (`drop-shadow: 0 0 20px rgba(0, 242, 255, 0.3)`) on hover and action trigger.
